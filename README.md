# 10. Neuro-Waste Monitor

## Concept
An environmental awareness tool that quantifies resource consumption. It translates minor daily habits into long-term data, helping users understand the cumulative impact of resource waste (Water, Electricity, or Gas).

## Innovation
The project features **Predictive Estimation Logic**. By taking a small sample of data (minutes of use), it projects the impact over an entire year. It also includes a "Comparison Logic" that translates abstract numbers (Liters) into relatable visuals (Swimming Pools) to drive behavioral change.

## How to Run
1. Run: `python main.py`
2. Enter the estimated flow rate (e.g., 5L/min for a tap).
3. Enter the daily duration.
4. See your projected yearly impact.
